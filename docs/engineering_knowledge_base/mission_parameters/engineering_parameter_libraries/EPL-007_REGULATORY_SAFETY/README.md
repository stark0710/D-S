Purpose

The Regulatory & Safety Library contains reusable engineering parameters related to system reliability, maintainability, redundancy, cybersecurity, failsafe behavior, regulatory compliance, operational risk, airworthiness, certification, and safety integrity.

Engineering Parameters defined within this library are platform independent.

Mission Categories shall reference these parameters.

Engineering Engines shall consume these parameters.

Engineering Parameter definitions shall comply with the Engineering Parameter Definition Standard (EPDS).

------------------------------------------------------------

## Scope

This library contains reusable engineering parameters related to safety constraints, reliability metrics, maintenance limits, redundancy architectures, failsafe conditions, and regulatory compliance categories.

Examples include

• System Reliability Requirement

• Maintainability Requirement

• Redundancy Requirement

• Cybersecurity Requirement

• Failsafe Behavior

• Regulatory Compliance Level

• Operational Risk Level

• Airworthiness Level

• Certification Requirement

• Safety Integrity Level

------------------------------------------------------------

## Out of Scope

The following engineering knowledge belongs to other Engineering Parameter Libraries.

• Flight Operations Parameters

• Payload Parameters

• Environmental Parameters

• Navigation Parameters

• Communication Parameters

• Performance Parameters

• Business Parameters

------------------------------------------------------------

## Engineering Principles

1.

Engineering Parameters shall be reusable.

2.

Engineering Parameters shall remain platform independent.

3.

Engineering Parameters shall comply with EPDS.

4.

Engineering Parameters shall not duplicate engineering knowledge.

5.

Mission Categories shall reference Engineering Parameters.
