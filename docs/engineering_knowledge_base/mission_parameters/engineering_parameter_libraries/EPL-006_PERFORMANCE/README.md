Purpose

The Performance Library contains reusable engineering parameters related to aircraft endurance, range, cruise speed, maximum speed, rate of climb, service ceiling, takeoff and landing distances, hover endurance, and mission availability.

Engineering Parameters defined within this library are platform independent.

Mission Categories shall reference these parameters.

Engineering Engines shall consume these parameters.

Engineering Parameter definitions shall comply with the Engineering Parameter Definition Standard (EPDS).

------------------------------------------------------------

## Scope

This library contains reusable engineering parameters related to aircraft flight performance, speeds, climb rates, operating ceilings, takeoff/landing limits, hover parameters, and operational availability.

Examples include

• Endurance Requirement

• Range Requirement

• Cruise Speed Requirement

• Maximum Speed Requirement

• Rate of Climb Requirement

• Service Ceiling Requirement

• Takeoff Distance Requirement

• Landing Distance Requirement

• Hover Endurance Requirement

• Mission Availability Requirement

------------------------------------------------------------

## Out of Scope

The following engineering knowledge belongs to other Engineering Parameter Libraries.

• Flight Operations Parameters

• Payload Parameters

• Environmental Parameters

• Navigation Parameters

• Communication Parameters

• Regulatory & Safety Parameters

• Business Parameters

------------------------------------------------------------

## Engineering Principles

1.

Engineering Parameters shall be reusable.

2.

Engineering Parameters shall remain platform independent.

3.

Engineering Parameters shall comply with EPDS.

4.

Engineering Parameters shall not duplicate engineering knowledge.

5.

Mission Categories shall reference Engineering Parameters.
