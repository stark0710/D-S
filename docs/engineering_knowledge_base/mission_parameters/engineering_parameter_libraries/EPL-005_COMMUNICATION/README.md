Purpose

The Communication Library contains reusable engineering parameters related to aircraft communication, telemetry, data links, networking, information exchange, communication reliability, and communication security.

Engineering Parameters defined within this library are platform independent.

Mission Categories shall reference these parameters.

Engineering Engines shall consume these parameters.

Engineering Parameter definitions shall comply with the Engineering Parameter Definition Standard (EPDS).

------------------------------------------------------------

## Scope

This library contains reusable engineering parameters related to communication capability, telemetry, communication performance, networking, redundancy, security, and data transmission.

Examples include

• Communication Method

• Communication Range Requirement

• Communication Reliability Requirement

• Communication Latency Requirement

• Communication Bandwidth Requirement

• Telemetry Requirement

• Video Transmission Requirement

• Multi-Vehicle Communication Requirement

• Communication Redundancy

• Communication Security Level

------------------------------------------------------------

## Out of Scope

The following engineering knowledge belongs to other Engineering Parameter Libraries.

• Flight Operations Parameters

• Payload Parameters

• Environmental Parameters

• Navigation Parameters

• Performance Parameters

• Regulatory & Safety Parameters

• Business Parameters

------------------------------------------------------------

## Engineering Principles

1.

Engineering Parameters shall be reusable.

2.

Engineering Parameters shall remain platform independent.

3.

Engineering Parameters shall comply with EPDS.

4.

Engineering Parameters shall not duplicate engineering knowledge.

5.

Mission Categories shall reference Engineering Parameters.
