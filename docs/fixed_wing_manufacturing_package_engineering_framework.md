# Fixed-Wing Manufacturing Package Engineering Framework

## 1. Manufacturing Philosophy

The **Fixed-Wing Manufacturing Package Framework** transforms finalized engineering geometries and parameter mappings into production-ready physical templates. It guarantees that designs produced within the studio translate seamlessly to actual fabrication processes:
*   **3D Printing**: Motor mounts and custom compartments.
*   **CNC Machining**: Spar brackets and firewall joints.
*   **Laser/Foam Cutting**: Wing ribs and flat composite board nesting.
*   **Manual/Composite Layup**: Wet composite skin laminations.

---

## 2. BOM Methodology

The **Bill of Materials (BOM)** is generated by extracting core assembly components alongside standard purchased hardware parts.
Each component is classified as:
*   **Fabricated**: Root wings, custom carbon fuselage pods, tail ribs. Includes material details and weight properties.
*   **Purchased**: Brushless motors, flight controllers, telemetry radios, batteries. Includes supplier names and catalog numbers.
*   **Fasteners**: Schedules detailing sizes (e.g. M5 nylon bolts) and torque limits.

---

## 3. Drawing Generation

Custom 2D engineering sheets are drawn to scale for fabricated parts:
*   Provides sheet formats (e.g. `A3`, `A4`) containing orthographic views (top, side, front), coordinate tables, and dimension margins.
*   Exports drawings as PDF templates.

---

## 4. Assembly Documentation

Step-by-step physical assembly sequences are formatted into guides:
1.  **Avionics Integration**: Placement of telemetry and controllers.
2.  **Firewall Rigging**: Bolting brushless motors.
3.  **Wing Joiners**: Sliding spar sleeves together.
4.  **Horns Rigging**: Hooking tail linkages.

Includes **Exploded Visual Views** (`.obj` meshes) to visualize individual sub-parts placements relative to the global origin.

---

## 5. Fabrication Workflows

Production code is compiled based on selected fabrication processes:
*   **CNC Machining**: G-code files (`.gcode`) containing coordinate feeds and spindle speeds.
*   **Laser Cutting**: DXF line files (`.dxf`) containing vector contours for outer outlines.
*   **3D Printing**: Slicer-ready STL mesh files (`.stl`).

---

## 6. Quality Assurance (QA) Methodology

Quality inspection testing checklists are drafted based on the target inspection level (e.g., `Standard` vs `Aerospace` constraints):
*   **Static margin confirmation**: Verifies CG alignment coordinates.
*   **Clearance audits**: Checks battery slots spacing.
*   **Structural strength tests**: High-G load spar bending tests (for Aerospace limits).

---

## 7. Cost & Budget Verification

The cost estimator (`CostEstimator`) computes complete unit production costs:
$$\text{Cost}_{\text{unit}} = \text{Components Cost} + (\text{Raw Materials Base} \times M_{\text{material}}) + (\text{Labor Hours} \times R_{\text{labor}}) + \text{Tooling Overhead}$$

The package is invalidated if this cost exceeds the mission constraints budget.

---

## 8. Strategy Extension Mechanism

To add a new manufacturing strategy:
1.  Inherit from `BaseManufacturingStrategy` in `manufacturing_strategy.py`.
2.  Override:
    *   `get_overhead_factors() -> Tuple[float, float]`
    *   `get_target_methods() -> List[str]`
    *   `get_recommendations() -> List[str]`
3.  Register in registry: `ManufacturingStrategyRegistry.register("strategy_id", StrategyClass)`.
